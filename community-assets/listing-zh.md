# Editable PDF Exporter

## Tagline

将 Figma 画板导出为多页 PDF，保留文字选择、搜索与编辑能力。

## Description

将 Figma 设计稿导出为多页 PDF，让支持的文字继续保持可选择、搜索和编辑。

Editable PDF Exporter 会读取当前页面的全部顶层画板，按画布位置排序，每个画板生成一页 PDF。你可以直接导出 PDF，也可以生成交接包，方便协作者接续编辑。

主要功能

• 支持普通中文、英文及可解析的混排文字。
• 将多个画板合并为一份 PDF。
• 一键生成包含 PDF、字体清单、兼容性提示和编辑说明的 ZIP 交接包。
• 全程本地处理，不上传设计稿或字体。

使用方法

1. 打开需要导出的 Figma 页面。
2. 运行 Editable PDF Exporter。
3. 点击「导出 PDF」，或点击「交接包」下载 ZIP。

文字与字体说明

普通文字保持可编辑。复杂文字效果、缺失字体或无法可靠重建的文字会自动转曲以保留外观；转曲文字不再支持文本编辑或搜索。原 Figma 设计稿不会被修改。

字体文件可读取且许可允许时，插件会嵌入字体；否则使用系统字体引用。接收方需安装被引用的字体，避免阅读器替换字体。使用 Adobe Acrobat 编辑时，即使字体已嵌入，也可能需要安装同版本字体。交接包不包含字体原文件。
