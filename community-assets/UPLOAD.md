# Figma Community 提交素材

插件名称：Editable PDF Exporter

| 发布表单字段 | 使用内容 |
| --- | --- |
| Tagline | `listing-en.md` 中的 Tagline；中文备选见 `listing-zh.md` |
| Description | `listing-en.md` 中的 Description；中文备选见 `listing-zh.md` |
| Thumbnail | `thumbnail-1920x1080.png` |
| Upload at least 1 image or video | `gallery-01-1920x1080.png` |

两张提交图片均为 1920 × 1080 PNG。封面用简洁的文档与文字选区示意表达产品用途；展示图使用当前插件实际 UI 渲染，填入示例页面名称和数量，右侧为输出文件示意，不是 Acrobat 编辑验证截图。

原图标保存在 `icon-original.png`，未重新绘制。HTML 文件和 `build-assets.cjs` 是可修改、重新生成图片的源文件，不需要上传。

本目录文案以当前代码和 README 的功能为准，替代旧 PUBLISHING.md 中关于“纯色描边可编辑”“复杂效果简化后仍可编辑”的过时表述。当前这些文字会转曲保留外观。
